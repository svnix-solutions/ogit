# Guides

Step-by-step instructions for common tasks. For the details of a feature, see its reference page.

## Running oGit

- [Try oGit with Docker Compose](./try-it): a complete oGit with PostgreSQL, S3 and Redis on your machine, with a demo repository.
- [Run oGit with Docker and PostgreSQL](./docker-postgres): a production-style setup with Docker Compose, PostgreSQL, and Nginx Proxy Manager for TLS.
- [Sign in with Keycloak](./sso-keycloak): OpenID Connect with group sync and admin rights from Keycloak.
- [Back up and restore](./backup-restore): scripts for local and S3 storage, and a restore drill.

## Working with oGit

- [Migrate from GitHub](./migrate-from-github): history, issues, pull requests and releases, from GitHub, GitLab or Gitea.
- [Run Actions on your own runner](./run-actions): register a runner and run a first workflow.
- [Publish a container image](./publish-a-container): by hand, then from a workflow on every tag.
